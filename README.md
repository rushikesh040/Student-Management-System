# Student-Management-System

📌 Project Overview

The Student Management System is a console-based Java application developed to practise Core Java, Object-Oriented Programming (OOP), and the Java Collections Framework.

The application manages student records and performs basic CRUD (Create, Read, Update, Delete) operations, including adding, displaying, searching, updating, and deleting student details.

The main objective of this project is to understand how different Java collections work and how they can be used together to manage data efficiently.

🚀 Features

Add new student records.

Display all student records.

Search for a student using their ID.

Update existing student details.

Delete student records.

Prevent duplicate student IDs.

Handle student records using multiple Java collections.

🛠️ Technologies Used

Programming Language: Java

Concepts: Core Java, Object-Oriented Programming

Collections Framework: ArrayList, HashSet, HashMap

IDE: IntelliJ IDEA / Eclipse

📚 Java Concepts Implemented

1. ArrayList

Used to store multiple student objects and display student records. It provides dynamic storage, allowing records to be added and removed at runtime.

2. HashSet

Used to maintain unique student IDs and prevent duplicate student records.

3. HashMap

Used to store student IDs as keys and Student objects as values. It helps retrieve student details using the corresponding ID.
